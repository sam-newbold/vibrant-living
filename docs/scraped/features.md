# Features

## Headline
Property Features — Everything You Need for a Perfect Stay

## Body copy
Set on two acres of beautiful tranquil gardens with stunning mountain views, Vibrant Living Retreat and Day Spa is a peaceful sanctuary just a five-minute drive (or scenic 15–20-minute walk) from Hanmer Springs village centre and the renowned thermal hot pools.

All accommodation options feature thoughtful touches designed for rest and rejuvenation — from private infrared saunas and outdoor hot tubs to organic breakfasts and holistic spa treatments.
